# Attribution

Railguard began as a fork of the original **Railguard** project created by
**Ari Choudhury** (`ari@railyard.tech`), published under the `railyard-dev`
GitHub organization at <https://github.com/railyard-dev/railguard>.

This repository (`github.com/ulises-c/railguard`, maintained by Ulises
Chavarria) was detached from that upstream in **July 2026** after the original
project went inactive for several months with outstanding pull requests. It now
develops independently.

## Relationship to upstream

- **`railguard` on crates.io** and the **`railguard.tech`** domain belong to the
  original `railyard-dev` project, not to this fork. Distribution and web
  presence for this fork are handled independently (see [`docs/REVAMP.md`](docs/REVAMP.md)).
- This fork carries forward the original architecture, default policy set, and
  documentation, and diverges through the fixes and direction tracked in
  [`docs/TODO.md`](docs/TODO.md) and [`docs/REVAMP.md`](docs/REVAMP.md).

Grateful acknowledgment to the original author for the foundation this project
builds on.
